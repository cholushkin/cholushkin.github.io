# 📰 Blog

A minimal news-style blog built with Markdown and Jekyll, statically generated and
hosted on GitHub Pages. No backend, no build-time JavaScript payloads for content —
pages, feeds, and category archives are rendered server-side by Jekyll.

Posts are written in Markdown and organized with categories like **thoughts**,
**projects**, and **articles**, providing a simple CMS-like workflow.

## 🚀 Live Site

👉 https://cholushkin.github.io/

## ✍️ How it works

- Posts live in `_posts/` as Markdown files with `categories` in their frontmatter.
- The home feed (`index.html`) is paginated natively by Jekyll (`jekyll-paginate`) —
  each page renders only the posts it shows, not the entire archive.
- Category filtering is a set of real static pages (`/thoughts/`, `/projects/`,
  `/articles/`), generated by `_layouts/category.html` from the list in
  `_config.yml`'s `blog.filters`. This is also what powers the filter links shown
  on the home page.
- Cheatsheets (`cheatsheets.md`) and Sandbox (`sandbox.md`) render their card grids
  from `_data/cheatsheets.yml` and `_data/sandbox.yml` via Liquid loops — no JS arrays.
- Snapshots (`snapshots.html`) is the one page that stays client-rendered by design:
  it fetches `data/snapshots.json` asynchronously and builds the gallery/viewer in JS.
- Shared look: `_layouts/default.html` provides the page shell (nav, `github-markdown-css`,
  `assets/css/style.css`); `_layouts/post.html` and `_layouts/category.html` both build
  on top of it, so there's one place that owns global styling.

👉 Fully static output — no backend required.

## 📂 Structure

```
_config.yml         # site settings: title/url, pagination, blog.filters (category list)
_data/               # cheatsheets.yml, sandbox.yml - content rendered via Liquid
_includes/           # nav.html, filters.html, post-card.html - shared page fragments
_layouts/            # default.html, post.html, category.html
_posts/              # blog posts (Markdown)
assets/css/style.css # single site-wide stylesheet (cards, buttons, filters, snapshots UI)
index.html           # paginated home feed
thoughts.md / projects.md / articles.md   # category archive stub pages
cheatsheets.md       # cheatsheets grid (from _data/cheatsheets.yml)
sandbox.md           # sandbox grid (from _data/sandbox.yml)
snapshots.html       # image gallery (fetches data/snapshots.json)
about.md             # about page
```

## 🧠 Goal

To create a simple, Git-based CMS-like blog system that is:

* easy to maintain
* fast (static, minimal payloads)
* flexible (new content = new file, not new code)

---

## ⚙️ Tech

* GitHub Pages (hosting)
* Jekyll + `jekyll-paginate` (static build & pagination)
* Vanilla JavaScript (only where genuinely interactive: the Snapshots gallery/viewer)

## 🛠️ How to add content

### New blog post

1. Create `_posts/YYYY-MM-DD-slug.md`.
2. Add frontmatter:
   ```yaml
   ---
   layout: post
   title: "My Post Title"
   date: 2026-08-28
   categories: [projects]
   ---
   ```
3. Write the post. Add `<!--more-->` on its own line where the preview excerpt
   (shown on the home feed and category pages) should cut off.
4. Drop any images under `assets/blog/` and reference them normally.

That's it — the post automatically appears in the paginated home feed and, if its
`categories` match a configured filter, on that category's archive page too.

### New filter / category

Filters (the buttons/links on the home page) and category archive pages
(`/thoughts/`, `/projects/`, ...) are driven from the same list, so they can't drift
out of sync:

1. Add the category slug to `blog.filters` in `_config.yml`.
2. Create a matching archive stub page at the repo root, e.g. `articles.md`:
   ```yaml
   ---
   layout: category
   title: Articles
   category: articles
   permalink: /articles/
   ---
   ```
3. Use that same slug in a post's `categories:` frontmatter list to have it show up there.

### New cheatsheet

Append an entry to `_data/cheatsheets.yml`:

```yaml
- title: My Cheatsheet
  url: /cheatsheets/my-cheatsheet.html
  categories: [javascript]
  thumbnail: /assets/thumbs/my-cheatsheet.jpg
```

Add the thumbnail under `assets/thumbs/`. No HTML or JS changes needed — the grid on
`/cheatsheets/` is rendered entirely from this file.

### New sandbox item

Append an entry to `_data/sandbox.yml`:

```yaml
- title: My Experiment
  url: /sandbox/my-experiment/
  description: One line describing the experiment.
  thumbnail: /assets/thumbs/my-experiment.jpg
  tags: [procedural, prototype]
```

Sandbox cards open in a new tab automatically.

### New snapshot

Add an entry to `data/snapshots.json` (title/text/images/priority — see existing
entries for the shape) and drop the corresponding images into
`assets/snapshots/full/` (full-size) and `assets/snapshots/thumbs/` (WebP thumbnail).

### Tuning

- Posts per page: `paginate` in `_config.yml`.
- Which filters/categories exist: `blog.filters` in `_config.yml`.
- Site title/description/URL: top of `_config.yml`.
- Shared visual style (cards, buttons, nav, filters): `assets/css/style.css`.
